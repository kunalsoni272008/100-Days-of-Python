🧩 Programs Practiced

1. 🔺 Area of a Triangle

Created a program to calculate the area of a triangle using its base and height.

Formula:

Area = (Base × Height) / 2

⸻

2. 🔄 Swap Two Variables

Created a program to swap the values of two variables.

Example:

Before swapping:
a = 10
b = 20
After swapping:
a = 20
b = 10

This exercise helped me understand how variables can be manipulated using arithmetic operations.

⸻

3. 🎲 Random Number Generator

Used Python’s built-in random module to generate a random number between 1 and 100.

import random
random.randint(1, 100)

⸻

4. 🌍 Kilometers to Miles

Created a unit conversion program that converts kilometers into miles.

Conversion:

Miles = Kilometers × 0.621

⸻

5. 🌡️ Celsius to Fahrenheit

Created a temperature conversion program.

Formula:

Fahrenheit = (Celsius × 9/5) + 32

⸻

6. 📅 Calendar Generator

Used Python’s calendar module to display the calendar for a selected month and year.

import calendar
calendar.month(year, month)

🧠 Key Concepts Learned

Type Conversion

User input is received as a string by default, so numerical calculations require conversion.

height = float(input("Enter height: "))

f-Strings

Used f-strings to create cleaner output:

print(f"Area of the triangle is {area}")

Python Modules

Python provides built-in modules that can be imported and used in programs.

import random
import calendar
